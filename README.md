# Internshala Internship Search Clone

A ReactJS-based internship search page inspired by Internshala's internship listing platform. This project replicates the core internship browsing experience with frontend filtering functionality and responsive UI.

## 🚀 Live Demo

https://iintershala.netlify.app/

## 📂 GitHub Repository

https://github.com/CrysPy-SAM/Intershala

---

## 📌 Features

- Fetch internship data from API
- Internship listing page
- Frontend filtering functionality
- Responsive UI design
- Clean and modular React components

### Filters Included
- Internship Profile
- Location
- Duration
- Stipend

---

## 🛠 Tech Stack

- ReactJS
- Vite
- JavaScript
- CSS
- Lucide React Icons
